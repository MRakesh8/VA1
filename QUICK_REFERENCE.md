## 💡 PRO TIPS

✨ **For Best Results**:
1. **Speak clearly** - No mumbling
2. **Wait 2 seconds** - For silence detection
3. **Use exact phrases** - "CSE" not "Computer Science"
4. **One command per time** - One at a time
5. **Quiet environment** - Minimal background noise

⚡ **Speed Up**:
- Numerical questions → instant response
- Specific facts → quick answer
- General questions → may take 1-2 seconds

🔧 **Troubleshooting Quick Fixes**:
- Not hearing? → Check volume in settings
- Can't give answer? → Try different wording
- Mic not working? → Reload page
- Wrong answer? → Clarify more details

## 🎯 COMMAND PATTERNS

**Pattern 1**: `"What is [topic]?"`
- Example: "What is machine learning?"
- Responds with AI knowledge

**Pattern 2**: `"Tell me about [college topic]"`
- Example: "Tell me about admissions"
- Uses college data first

**Pattern 3**: `"[Action] to [target]"`
- Example: "Send message to John"
- Performs automation task

**Pattern 4**: `"Open/Go to [website]"`
- Example: "Open YouTube"
- Navigates to URL

**Pattern 5**: `"Set/Create [reminder/timer/alarm]`
- Example: "Set timer for 10 minutes"
- Schedules event
